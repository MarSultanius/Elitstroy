# Элитстройсервис-Актобе — сайт компании

Статический одностраничный сайт ТОО «Элитстройсервис-Актобе» (строительная компания, с 2001 года).

- Дневная и ночная тема (переключатель в шапке, выбор запоминается; по умолчанию — как в системе)
- Адаптивная вёрстка от 320px (смартфон) до 4K-телевизора
- Каталог из 40 реализованных объектов с фильтром по категориям и поиском (`js/projects.js`)
- Форма заявки отправляет сообщение в WhatsApp или на email (без сервера)

## Структура
```
index.html        — страница
css/styles.css    — стили и темы
js/main.js        — тема, меню, фильтр объектов, форма
js/projects.js    — список объектов (редактировать здесь)
assets/           — логотип и favicon
```

## Запуск
Откройте `index.html` в браузере или разместите папку на любом хостинге (GitHub Pages, Netlify и т.п.).
